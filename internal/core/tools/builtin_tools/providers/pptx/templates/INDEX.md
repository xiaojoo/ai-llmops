# 内置 PPT 模板索引

供 LLM 选择模板使用（`pptx_from_template` 工具的 `template` 参数传 slug）。

| slug | 名称 | 风格 | 适用场景 |
|---|---|---|---|
| minimal-business-summary | 简约商务总结汇报 | 简约商务 | 年度/季度总结、商务汇报、项目复盘 |
| thesis-novice | 多专业开题方法论库 | 学术绿 | 开题报告、学术答辩、方法论展示 |
| report-massive-reports | 汇报合辑·工作汇报与竞聘 | 商务蓝 | 工作汇报、述职、竞聘陈述 |
| architecture-deck | 领导爱的架构图合辑 | 企业蓝 | 技术架构、系统设计、流程方案 |
| competition-speech | 竞聘述职合辑 | 正式蓝 | 竞聘演讲、述职答辩、团队宣讲 |

每个模板目录：`template.pptx`（母版）+ `detail.json`（页面/槽位元数据）。

> 模板素材来自 GordenPPTSkill（GitHub GordenSun/GordenPPTSkill），
> 仅供学习与研究使用，严禁商用。
